About this viewer

Open Liveries describes airline paint schemes as open data, from which colors go where to what the titles say and where the logos sit. Each scheme is measured from openly licensed photos and the airlines’ own images, and a small renderer draws it. The data is CC0 and the code is MIT. Use both for anything you like.

What you’re seeing

Every picture here is drawn live from a scheme’s JSON file rather than taken from a photo. The cards in the list all use the same simple placeholder airplane.

Open a scheme to see it in 3D, from both sides and from below. It’s drawn on the type it was measured on if we have that type’s real outline and on the placeholder if we don’t.

What you can do

  • Search by airline, scheme or registration and filter by kind.
  • Open a scheme and drag the 3D model to turn it. Scroll or pinch to zoom and press Spin to stop it.
  • Step through every measured type with ‹ and › (or the arrow keys). Any livery fits any type. Try Pan Am’s 1985 cheatline on a 787 and make planes that never flew.
  • Load your own aircraft’s shape file with Your shape… to see any scheme on it.
  • Share what you see with the page’s link, which keeps the scheme (#ICAO/id) and the type (?shape=B789).

What it can’t do yet

  • The default airplane is a placeholder. The narrowbody, widebody and regional jet are simple generic models rather than any real type. Eighty-odd types have their real outline, measured mostly from the makers’ own drawings. Everything else goes on a placeholder.
  • Logos show as dashed boxes. The label in the box is the logo’s name, like “globe” or “logo”. Airline logos are trademarks that belong to the airlines. Open Liveries describes each one in words and says where it goes without copying it. Apps that use the data draw their own simple marks.
  • The lettering is a stand-in. Titles are set in the closest common typeface, not the airline’s own.
  • It can be off. Colors and positions are measured by hand from photos. Each scheme lists its sources and how sure we are.
  • Some schemes aren’t drawn yet. Some have only words so far and show their airline’s usual scheme with a note. Drawn only hides them.

Help out
